# C-Sharp-Projects
This repo is for assorted projects and assignments in part with The Tech Academy

## Projects

* Twenty-One
* Car Insurance Approval
* Student Daily Report
* Web App Challenge
* Numerous Other Small Assignments

### Twenty-One
- Console application simulating a game of Blackjack, written in the OOP paradigm. Including multiple classes
such as: Twenty-One Rules, Player, and Game.

### Car Insurance Approval
- Basic console application where user inputs primitive data types such as: bool, and int, 
to determine if they would be approved for car insurance.

### Student Daily Report
- Basic console aaplication where user inputs for primitive data types w/ if/else statement to determine 
need for instructor help. App is also used to demonstrat simple string concatenation.

### Web App Challenge
- One of the final assignments in the course. Student demonstrates being able to spin up a basic ASP.NET Core web app. 
This includes a webpage that display the current time base on he computer's web browser. This app was publised live via
the Azure collection of services.

### Numerous Other Small Assignments
- Repo includes a number of other small assignments and projects where student must demonstrate concepts and common practices
in the C# programming language. Such as: Try/Catch, Parsing Enums, Methods in Classes, Math Operators, Polymorphism, and many more.
